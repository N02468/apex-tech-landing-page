Interface Segregation Principle

The Interface Segregation Principle (ISP) is one of the SOLID principles of object-oriented design. It states that clients should not be forced to depend on interfaces they do not use. In other words, a class should not be required to implement interfaces that it does not need.

By adhering to the ISP, developers can create more modular and maintainable code. It encourages the creation of smaller, more focused interfaces that are easier to understand and implement. This leads to better separation of concerns and promotes code reusability.
